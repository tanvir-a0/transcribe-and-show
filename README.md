# Live Procedural Music Visualizer

A fully automated, AI-driven, real-time procedural music visualizer designed for a 128x64 monochrome OLED display powered by an ESP32.

This project automates the process of generating flawless, millisecond-accurate lip-synced procedural graphics for any song. It takes a YouTube link or local audio file, transcribes it using OpenAI's Whisper AI, and hot-loads complex mathematical art generated by an LLM to render stunning OLED visuals in real time.

## Architecture

1. **AI Audio Transcription (`generate_timeline_whisper.py`)**
   Downloads audio directly from a YouTube link (via `yt-dlp`) or takes a local media file. It uses OpenAI's Whisper model to listen to the song and generate a millisecond-accurate `timeline.json` mapping every word and instrumental gap. It also generates a customized `llm_prompt.txt`.

2. **LLM Procedural Art (`generated_visuals.py`)**
   You pass the generated `llm_prompt.txt` to an LLM (like ChatGPT or Claude). The LLM writes highly complex, context-aware mathematical graphics (using Trigonometry and Pillow) tailored specifically to the song's semantic meaning.

3. **Live Stream Engine (`live_streamer.py`)**
   The core desktop engine. It reads the `timeline.json`, hot-loads the LLM's `generated_visuals.py`, perfectly syncs the rendering to the actual audio time, packs the 128x64 image into a binary SSD1306 format, and streams it over Serial to the ESP32.

4. **ESP32 Firmware (`node_code/`)**
   Custom C++ firmware for the ESP32 that receives the binary stream at 1,000,000 baud and instantly draws it to the OLED display.

## Installation

Ensure you have Python and Node.js installed on your system. 

1. Install the required Python libraries:
   ```bash
   pip install -r requirements.txt
   ```

2. *(Windows Users)* Install Node.js to solve YouTube's anti-bot protections:
   ```bash
   choco install nodejs -y
   ```

## Usage

**Step 1: Generate the Timeline & Prompt**
Run the Whisper AI transcription script:
```bash
python generate_timeline_whisper.py
```
Paste a YouTube link (or leave blank to select a local `.mp3`/`.mp4` file). The script will download the audio, transcribe the exact word timestamps, and output `timeline.json` and `llm_prompt.txt`.

**Step 2: Generate the Art**
Copy the text inside `llm_prompt.txt` and give it to an LLM. Save the Python code it gives you back as `generated_visuals.py` in this folder.

**Step 3: Stream to the Display!**
Make sure your ESP32 is plugged in and running the firmware in the `node_code/` folder.
Run the live streamer:
```bash
python live_streamer.py
```
Press `ENTER` in the console exactly when you hit play on the song, and watch the incredibly complex procedural graphics sync perfectly with the music on your OLED display!
